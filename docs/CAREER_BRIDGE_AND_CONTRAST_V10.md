# Mzansi Pathways v14 — Career-to-Evidence Bridge & High-Contrast Accessibility

- **Live Career-to-Evidence Bridge (`🎯 Careers`):** Compares each career's core skills directly against the learner's real `Evidence Vault` entries so students see which skills they already have proof for and which ones still need a starter project.
- **High-Contrast Mode (`HC` button):** Designed for bright outdoor mobile screens and low-vision accessibility (`body.high-contrast`).
- **30-Gate Audit Certificate (`scripts/generate_audit_bundle.py`):** Produces `audit_summary.json` confirming all 30 verification, auth, RLS, failsafe, and integrity gates passed.
