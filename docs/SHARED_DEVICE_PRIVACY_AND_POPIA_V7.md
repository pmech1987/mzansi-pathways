# Mzansi Pathways v11 — Shared-Device Privacy & POPIA Compliance Guide

## 1. Why Shared-Device Privacy Matters in South Africa
Many learners access career and study tools on a parent's phone, a school computer lab, or a public library/internet café PC.
- **1-Tap Privacy Wipe (`wipeLocalProfile()` in `🔐 Sync`):** Clears all saved marks, Evidence Vault items, CV contact details, and Plan A/B/C from `localStorage` immediately so the next person using the device sees zero personal data.
- **No Forced Account or SA ID:** Learners can check APS, bottlenecks, and routes without creating an account or typing an ID number.
- **Honest Motivation Letters (`buildHonestMotivationLetter()`):** Generates a clean, editable application cover letter using only the learner's own confirmed Evidence Vault entries — never fabricated percentages or fake work history.
