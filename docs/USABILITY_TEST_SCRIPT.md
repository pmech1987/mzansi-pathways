# Mzansi Pathways — 5-Learner Offline Usability Script & Observation Sheet (X6)

Measure real learner success **without any tracking or analytics** by observing 5 Grade 10–12 learners on a 360px Android phone (including Airplane Mode).

## Tasks (Time & Record Friction Only — No Learner Names Recorded)
1. **Enter Marks (Target: <= 4 taps to first APS):** Enter 7 Matric subjects (including one decimal mark like `65.5` and clearing one mark). Note if any keyboard or label confused them.
2. **Find Matching Universities:** Open **Study → Institutions**, tap **Only where I match**, pick the top university, and open its matching courses.
3. **Explore a Near Miss:** Find one "Close" course and read why it is short + what next step is suggested.
4. **Add a Local Municipality in Work → Sources:** Type a town/municipality (e.g. `Thembisile`) without typing a URL and tap **+ Track**.
5. **Privacy / Shared PC Check:** Open **Settings**, toggle **Shared PC / Class Mode**, then tap **Delete everything**, close Chrome, and reopen to confirm zero data remains.
