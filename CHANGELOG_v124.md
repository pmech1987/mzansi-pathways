# Mzansi Pathways v124 — All 11 Official Written SA Languages & Match-Only Filter

## Upgrades
- **All 11 Official Written South African Languages (`js/i18n.js`):** Added draft translations (`reviewed: false`) for **Sepedi (`nso`)**, **Setswana (`tn`)**, **Tshivenda (`ve`)**, and **isiNdebele (`nr`)**, completing all 11 official written languages alongside English, Afrikaans, isiZulu, isiXhosa, Sesotho, siSwati, and Xitsonga.
- **1-Tap "Only where I match" Filter (`js/modules/funding.js`, `js/app.js`):** Lets learners hide every university/college with 0 matches so they see only institutions where they qualify or are close, sorted from most matching courses down.
- **Clean Parent/Teacher Print Export (`css/civic_mobile_a11y.css`):** Hides sub-tabs, filter bars, and Class Mode banners in `@media print` for clean PDF handouts.
- Added `scripts/test_v124_all_11_languages_and_match_filter.py` into `scripts/run_all_checks.py` and bumped `sw.js` to `mzansi-pathways-v124`.
